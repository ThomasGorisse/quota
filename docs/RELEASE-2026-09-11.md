## Defects found and corrected

- Cached provider measurements now carry their actual time and independent stale state. A
  fresh Codex response cannot make a stale Claude response appear fresh. Retention: 24h locally.
- Invalid percentages are discarded rather than converted to zero used / 100% available.
- Cached values no longer fabricate new history samples. Hosted history expires in 24h;
  snapshots expire seven days after the last ingest.
- Store descriptions/privacy policy previously described a self-hosted-only system and claimed
  disconnecting deleted relay data. Updated to the actual hosted architecture.
- Public setup/download replaces links to an inaccessible private GitHub repository.
- Apple App Group storage alone cannot synchronize two physical devices; WatchConnectivity
  and the signed keychain access group need to work, not just simulator demo mode.
